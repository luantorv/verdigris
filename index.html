CREDIT / COLOR ORIGIN

Verdigris está fuertemente inspirado en el esquema Tapetum Verdigris de Țugui Dragoș. A partir de esa referencia cromática, este proyecto desarrolla reglas propias para geometría, densidad, componentes e integración entre aplicaciones.
